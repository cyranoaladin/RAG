# Référentiel — Épreuve anticipée de mathématiques (EAM)

> Fiche corpus transversale. Tous les élèves de première, fin de première (première session : 2026).

## 1. Format
- Écrit **2 h**, **sans calculatrice**, noté sur 20, **coefficient 2**.
- Partie 1 : QCM d'automatismes (6 points). Partie 2 : 2 à 3 exercices de raisonnement (14 points).

## 2. Sujets différenciés
- Voie générale **avec** spécialité mathématiques ;
- Voie générale **sans** spécialité mathématiques (enseignement spécifique) ;
- Voie technologique.

## 3. Compétences
- Calculer, raisonner, modéliser, programmer (Python).

## 4. Notes RAG
- Collection cible : `rag_nexus_exams_anticipee_maths`.
- Métadonnée `sujet_variant` obligatoire (gen_spe / gen_sans_spe / techno) — jamais devinée.
